Patates Yaprağı Hastalık Tanıma - VGG16 (PyTorch)

Bu proje, VGG16 derin öğrenme modelini kullanarak patates yapraklarının sağlıklı mı, erken yanıklık mı, yoksa geç yanıklık mı olduğunu sınıflandırır.


📌 İçerik

pot.ipynb → VGG16 modelini kullanarak veri kümesiyle eğitme kodu.

modeltest.ipynb → Eğitilmiş modeli kullanarak bir görüntüyü sınıflandırma kodu.

vgg16_model.pth → Kaydedilmiş model ağırlıkları (bu dosyayı yükleyerek test yapabilirsiniz).
